# The portable archive — round 7 (#1002): a switch, not a hint

subtle." (owner, 2026-09-20). Text with a rule under it is a hint; this is
a switch. The two tabs are one joined pair at the far end of the card head,

the heading on the same line if it fits, else wraps under it. Panels,
copy, manifest, fields, keyboard and aria are round 4 verbatim; the
`role=tablist/tab/tabpanel` and ← → keys are unchanged.
