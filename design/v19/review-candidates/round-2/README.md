# Review card readings — round 2 (#1008)

Round 1 verdict (owner, 2026-09-16): "29. Lines is better. Neither is very
elegant." B carried forward; this round takes the boxes away.

Both concepts share one vocabulary. No boxes, no chips. Each reading is a
dot and a value, with the line Orbit read it from in faint type after it:

- filled dot — the reading in force (what Add to orbit will save)
- hollow dot — another reading; tap it and the dots swap
- dashed dot — "type it": opens a typing box in that row

Same story as round 1: home insurance renewal (three readings for provider,
renews and cost) and a boiler service with no cost read at all.

## C — list (`c-list.html`)

Every reading is a row, all the time. The reader sees the whole argument
without tapping, at the cost of height: the insurance card is about fourteen
rows deep.

## D — quiet (`d-quiet.html`)

One row per field: the reading in force and its line. Under it, a faint
"or 2 more · type it" link unfolds the rest (shown open on "renews"). A
field with one reading says only "type it"; a field with none opens the
typing box straight away.

Fable's recommendation: **D**. It reads like a finished record until the
reader doubts a value, and one tap turns it into C for that field only.
