## A — asterisms

A new section's mark is a small **asterism**: a few pen-drawn stars joined
by the same line the dial is drawn with. Nothing is filled; the dot still
carries the colour. Seven figures — hook, kite, ladle, cross, bow, wedge,
belt — plus the five shipped glyphs make **twelve, the cap**, so the set
never runs out and never needs a thirteenth.

**Assigned, then swappable.** A new row arrives wearing the first figure
the pen has not used; there is nothing to fill in. On a user-named row the
mark is a button: press it and the pen's unused figures line up under the
row, the worn one ringed (shown open on Allotment, the row just added).
Pick one or leave it. Shipped sections' marks are not buttons.

**Five inks, twelve marks.** The accents recycle after five — Boat is sage
like Home. The line tells them apart, so colour is never the only
difference (WCAG 1.4.1). The manifest card shows the 14 px print beside
entries; the set card shows all twelve at 20 px and 14 px.

Why not the other answers: assign-by-name fails oddly on "Mum's flat"; dot-
only makes the five shipped sections a privileged class; a picker of
pictograms needs a big set to feel like a choice and breaks one pen's hand.
An asterism is honest for any name because it depicts nothing.
