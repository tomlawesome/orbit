# PDF producer fixtures

`chromium-synthetic.pdf` is a small, non-private PDF generated by the installed
Playwright Chromium producer from fixed synthetic HTML. It is independent of
the hand-built structure fixtures in `tests/support/generated-pdf-documents.ts`.

Regenerate it locally with:

```text
node scripts/generate-pdf-fixtures.mjs
```

The Playwright and Chromium versions come from the repository lockfile and
installed browser cache. Do not replace this fixture with owner documents or
external copyrighted PDFs.
