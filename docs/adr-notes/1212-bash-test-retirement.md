# #1212: retiring the bash install test suite

#1212 moved install's file work into the TypeScript engine
(`src/lib/install-orchestrator.ts`), leaving `scripts/install.sh` as the
bootstrap and Compose shell around it, so the old 131-test
`scripts/install.test.mjs` was testing code that no longer exists. Build note
D10 lets a bash suite be replaced only once every test in it maps to a test
that proves the same behaviour. The table below is that mapping. The bash
output the engine is still compared against was captured from `9757e42f` into
`src/lib/__fixtures__/` (its README says how); the parity tests title each case
`agrees: <case name>`.

Each row is an old test title and the test that now proves the same behaviour
(`file › test title`), or `retired:` with the reason the behaviour no longer
exists by design. `open:` would mark a behaviour nothing covers yet; none
remain, so the old suite can be deleted.

Test files named below, by directory:

- `src/cli/`: `orbit.install.test.ts` (new)
- `src/lib/`: `install-orchestrator.test.ts` (new), `install-transaction.test.ts`,
  `install-transaction.parity.test.ts`, `database-volume-safety.test.ts`,
  `database-volume-safety.parity.test.ts`, `target-identity.test.ts`,
  `deployment-profile.test.ts`, `oidc-discovery.test.ts`,
  `launcher-config-tree.test.ts`, `deployment-assets.test.ts`,
  `configuration-migration.test.ts`, `configuration-migration.parity.test.ts`,
  `guided-configuration.test.ts`, `guided-configuration.parity.test.ts`,
  `configure-engine.retired-bash.test.ts`
- `scripts/`: `install.test.mjs` (the new bootstrap and Compose suite),
  `installer-simulation.test.mjs`
